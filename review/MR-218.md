## 1. Naming of TaminCheckbox1 — Low ✅

**File:** `core-ui/src/commonMain/kotlin/com/tamin/taminhamrah/ui/components/TaminStaticCheckbox.kt:32`

```kotlin
@Composable

    checked: Boolean,
// ...
```


The component and file are named with a 1 suffix (TaminCheckbox1), likely to avoid a naming collision with the existing TaminCheckBox. Adding a numeric suffix is an anti-pattern (Clean Code / SOLID) and makes the component's purpose unclear to other developers.

As described in the documentation, this is a purely presentational checkbox with no built-in padding. It should have a descriptive name reflecting that purpose.

**Suggested change:**
Rename the file and function to something descriptive like TaminStaticCheckbox, TaminPresentationalCheckbox, or TaminUnpaddedCheckbox.
Alternatively, refactor the existing TaminCheckBox to optionally disable its padding/click wrapper and delete this duplicate entirely.
