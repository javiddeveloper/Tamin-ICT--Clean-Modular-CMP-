## 1. String concatenation without delimiter in key — Low

**File:** `feature/workshops/src/commonMain/kotlin/com/tamin/taminhamrah/feature/workshops/ui/assignerContracts/AssignerContractsScreen.kt:180`

`kotlin
// current code
key = { it.card.workshopId + it.contractRow + it.contractSequence },
`

String concatenation without delimiters can lead to key collisions in Compose. For example:
workshopId="12", contractRow="", contractSequence="3" becomes "123"
workshopId="1", contractRow="2", contractSequence="3" becomes "123"
Compose key requires the result to be unique across all items to track recomposition accurately.

**Suggested change:**
Use string templates with a delimiter like an underscore:

`kotlin
// proposed code
key = { "${it.card.workshopId}_${it.contractRow}_${it.contractSequence}" },
`
