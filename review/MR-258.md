```

```

`FeatureFlag.OBJECTION_INSURANCE_HISTORY_45` (id 45) was renamed to
`FeatureFlag.OBJECTION_INSURANCE_HISTORY_LEGACY` by an earlier merge, but
`FeatureNavigation.kt`'s `when` clause still references the old name. This line is unchanged by
this MR's diff (which only touches `core-ui` toast files) and the same failure reproduces
identically against `develop`'s own current tip (`b9501502f`) — confirmed directly by reading the
enum (`core/core-domain/.../model/common/FeatureStatus.kt`, which only defines
`OBJECTION_INSURANCE_HISTORY(42)` and `OBJECTION_INSURANCE_HISTORY_LEGACY(45)`, no `_45` suffix
variant) and the source of `origin/develop:shared/.../FeatureNavigation.kt`. This MR does not need
to fix it, but merging it as-is still leaves `:shared` broken until whichever MR fixes the stale
reference lands — flagging so it isn't mistaken for something this MR introduced or needs to fix
itself, and so it doesn't get lost in isolated per-MR review.

**Suggested change:** no action required in this MR. Tracked separately; MR !257 happens to fix
this stale reference as a side effect of unrelated cleanup.

## What was done well

- **Icon selection consolidated correctly.** `TaminToastIcon(type, tint)` in the new
  `MorphingToast.kt` replaces what was previously a duplicated per-call-site `when` — a genuine
  de-duplication, matching every icon/type pairing the old `AppToaster.kt` had.
- **No coroutine-scope leaks.** All `LaunchedEffect` usages across `Toaster.kt`/`MorphingToast.kt`
  are Compose-managed (keyed on `state.toasts`, `dismissing`, etc.) — no raw `GlobalScope.launch`
  or manually retained scopes.
- **Dead parameters removed cleanly.** `showCloseButton`, `richColors`, `darkTheme` were unused in
  `AppToaster.kt` and are removed along with their call sites, not just left unreferenced.
